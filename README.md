## 💡 About The Project

Most online PDF converters force users to upload confidential contracts, financial filings, and medical documents to unknown third-party cloud servers, posing severe privacy risks and slow processing times.

**PDF Genius App** solves this by separating document manipulation from AI intelligence:
1. **Local-First Execution:** Standard PDF modifications (*Merge, Split, Compress, Watermark, Protect, Image Conversions*) run **entirely in the user's local browser memory** using `pdf-lib`. No files are uploaded to external servers.
2. **Contextual AI Intelligence:** When AI features are activated, sanitized textual tokens are streamed securely through an ephemeral server-side **Google Gemini 3.8 Flash** pipeline, delivering high-density executive intelligence, answers, and summaries in seconds.

## 💻 Tech Stack & Engineering Highlights

* **Frontend Framework:** `React 19` + `TypeScript`
* **Styling & Design System:** `Tailwind CSS v4` with custom glassmorphism, responsive grid layouts, and animated transitions.
* **PDF Engineering:** `pdf-lib` (pure JavaScript binary stream processing) + HTML5 2D Canvas.

## 🚀 Getting Started

### 1. Clone the Repository
```bash
git clone https://github.com/<your-username>/pdf-genius-app.git
cd pdf-genius-app
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Configure Environment Variables
Copy `.env.example` to create your `.env` file:
```bash
cp .env.example .env
```
Add your Google Gemini API key:
```env
GEMINI_API_KEY="your_actual_gemini_api_key_here"
PORT=3000
```
> *Note: If no API key is set, the app gracefully activates its built-in local semantic parser so all features continue to work smoothly without errors.*

### 4. Launch Development Server
```bash
npm run dev
```
Navigate to **`http://localhost:3000`** in your browser.

## 🌐 Deploy to GitHub & Vercel in 2 Minutes

### Step 1: Push to GitHub
```bash
git init
git add .
git commit -m "feat: PDF Genius App - Full AI Document Suite"
git remote add origin https://github.com/<your-username>/pdf-genius-app.git
git branch -M main
git push -u origin main
```
*(The repository includes a comprehensive `.gitignore` safeguarding all environment keys and build artifacts).*

### Step 2: Deploy to Vercel
1. Sign in to [Vercel](https://vercel.com) and click **"Add New Project"**.
2. Import your GitHub repository **`pdf-genius-app`**.
3. Framework Preset: **Vite** *(detected automatically)*.
4. Under **Environment Variables**, add:
   * **Key:** `GEMINI_API_KEY`
   * **Value:** *[Your Gemini API Key]*
5. Click **Deploy** — your application will be live globally in under 60 seconds with full SPA routing handled by `vercel.json`!

## 🛡️ Security & Privacy Principles

* 🔒 **Zero Data Retention:** User files are processed strictly in RAM and never saved to persistent disk storage.
* 🔑 **Protected Secrets:** API keys are quarantined on the server side and never bundled into client browser distributions.
* 🛡️ **Defensive Fallbacks:** All endpoints feature graceful fallbacks to guarantee uninterrupted uptime even during upstream quota spikes.
